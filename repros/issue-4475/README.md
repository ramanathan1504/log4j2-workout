# Log4j issue #4475 reproduction

https://github.com/apache/logging-log4j2/issues/4475

> `additivity` is accepted on `<Root>` but not on `<Logger>` by the published `log4j-config-2.xsd`

## Reproduction

```bash
cd log4j-issue-4475-repro
./run.sh            # Log4j 2.26.1
./run.sh 2.25.5     # any other release
```

`src/main/resources/log4j2.xml` is the reporter's configuration unchanged.
`log4j2-no-additivity.xml` drops the two `additivity` attributes, and
`log4j2-root-additivity.xml` puts one on `<Root>` instead. `Main.java` loads the
reporter's file and prints `LoggerConfig.isAdditive()` for both loggers.
JDK 17, macOS, `xmllint` from libxml2.

## Results

Schema: `https://logging.apache.org/xml/ns/log4j-config-2.xsd`, `last-modified: Mon, 12 Jan 2026 13:13:21 GMT`, 305,189 bytes, copy in `output/`.

| Input | `xmllint --schema` |
|---|---|
| `log4j2.xml` (reporter) | fails: `attribute 'additivity': The attribute 'additivity' is not allowed.` at lines 12 and 15 |
| `log4j2-no-additivity.xml` | validates |
| `log4j2-root-additivity.xml` | validates |

| Log4j | Output | `isAdditive()` |
|---|---|---|
| 2.26.1 | each message printed once | `false`, `false` |
| 2.25.5 | each message printed once | `false`, `false` |

Log4j accepts and applies the attribute. Only the published schema rejects it.

## Mechanism

The schema is generated by `log4j-docgen` (apache/logging-log4j-tools) from the plugin
descriptors. The `Logger` builder declares `private Boolean additivity` (boxed); the
`Root` builder declares `private boolean additivity` (primitive). Up to 0.9.0 (2024-05-14,
the latest release) `SchemaGenerator.isBuiltinXmlType` knows only primitive types and
`java.lang.String`, so every boxed attribute is left out. apache/logging-log4j-tools#190
(`bcb423cc3d`, merged 2025-06-03, fixes apache/logging-log4j-tools#135) adds the boxed
types. It has not been released, and the schema has not been regenerated since.

Same class in the published schema, `origin/2.x` @ `953933a9b7`: 16 of 17 boxed
`@PluginAttribute` / `@PluginBuilderAttribute` fields are missing:
`LoggerConfig.additivity`, `RegexFilter.useRawMsg`, `SocketOptions` (9 of its 10
attributes), `ScriptFile.isWatched`, `PoolableConnectionFactoryConfig.defaultAutoCommit`,
`defaultQueryTimeoutSeconds`, `defaultReadOnly`. `Rfc5424Layout.enterpriseNumber` is present.

Raw output in `output/`.
